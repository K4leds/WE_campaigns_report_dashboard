## 🎨 Color & Symbol Guide

### Trend Indicators
- **↗** Green = Increasing (Good for revenue, conversions, etc.)
- **→** Blue = Stable (< 1% change)
- **↘** Red = Decreasing (Bad for revenue, conversions, etc.)

### Alert Symbols
- **✅** = Success / Positive insight
- **⚠️** = Warning / Needs attention
- **🚨** = Critical / Immediate action required
- **ℹ️** = Information / Neutral insight

### Delta Colors
- **Green background** = Positive change (improvement)
- **Red background** = Negative change (decline)
- **Blue background** = Neutral/stable

## 📱 Example User Flow

### Scenario: Weekly Performance Check

**Step 1: Set Date Range**
```
Sidebar → Date Range: 
From: Dec 10, 2024
To: Dec 16, 2024
```

**Step 2: Enable Comparison**
```
Sidebar → Compare With: "Week over Week"
```

**Step 3: See Overview**
```
Navigate to Overview page
→ See all metrics with % changes
→ Note: Revenue up 15.2%, Conversions up 8.5%
```

**Step 4: Detailed Analysis**
```
Navigate to Comparisons page
→ Review executive summary
→ Check channel-level changes
→ Read AI-generated insights
→ Take action on recommendations
```

**Step 5: Campaign Deep Dive**
```
Navigate to Campaigns page
→ See comparison banner
→ Drill down to specific campaigns
→ Identify which campaigns drove the improvement
```

## 💡 Pro Tips

### Tip 1: Quick Weekly Review
```
Every Monday:
1. Set range to last week
2. Compare with "Week over Week"
3. Review Comparisons page for insights
4. Share screenshot with team
```

### Tip 2: Campaign Launch Analysis
```
After campaign ends:
1. Set range to campaign duration
2. Use "Custom Date Range" for pre-campaign period
3. Apply campaign filter
4. Export Comparisons page for report
```

### Tip 3: Monthly Business Review
```
Start of each month:
1. Set range to previous month
2. Compare with "Month over Month"
3. Navigate to each page for comprehensive view
4. Prepare presentation from Comparisons insights
```
