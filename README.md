# WebEngage CSV Dashboard

An interactive dashboard for analyzing WebEngage CSV exports using Streamlit.

## Features

- Automatic data cleaning and normalization
- Key analyses: Top campaigns, journeys, segments, channels
- Interactive filtering by date, channel, campaign, segment
- Export cleaned data and aggregated reports as CSV or Excel

## Installation

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run the app:
   ```
   streamlit run app.py
   ```

3. Upload your WebEngage CSV file and explore the dashboard.

## Usage

Upload a CSV file with the standard WebEngage headers. The app will clean the data and provide various analyses and visualizations.
