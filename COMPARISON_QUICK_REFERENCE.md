# 📊 Quick Reference: Period Comparison Feature

## How to Use

### Step 1: Enable Comparison (Sidebar)
Look for **"📊 Comparison Settings"** in the sidebar:
```
Compare With: [Select Option ▼]
```

### Step 2: Choose Comparison Type
- **None** - No comparison
- **Previous Period (Auto)** - Smart auto-comparison
- **Week over Week** - Last 7 days vs previous 7 days
- **Month over Month** - ~30 days comparison
- **Quarter over Quarter** - ~90 days comparison
- **Custom Date Range** - Pick your own dates

### Step 3: View Results
Comparison data appears on these pages:
- ✅ **Overview** - Main metrics with % changes
- ✅ **Comparisons** - Detailed analysis with insights
- ✅ **Campaigns** - Campaign performance changes
- ✅ **Journeys** - Journey performance changes

## What You'll See

### On Every Metric
```
Total Revenue
52.3K SAR
↗ +15.2% (compared to previous period)
```

### On Comparisons Page
- 📊 Executive Summary with overall trend
- 📈 Detailed metrics table (current vs comparison)
- 🎨 Visual charts (bar/line graphs)
- 📡 Channel-level breakdown
- 💡 AI-generated insights & recommendations

## Quick Tips

1. **Best for Weekly Reviews**: Use "Week over Week"
2. **Best for Monthly Reports**: Use "Month over Month"
3. **Best for Campaigns**: Use "Custom Date Range" to compare campaign periods
4. **Want Fair Comparison**: System auto-calculates daily averages
5. **Multiple Filters**: Apply filters (channels, campaigns) - they affect both periods

## Understanding Trends

| Symbol | Meaning | Color |
|--------|---------|-------|

## Example Scenarios

### Scenario 1: This Week vs Last Week
1. Set date range: Dec 10-16
2. Choose: "Week over Week"
3. Result: Compares to Dec 3-9

### Scenario 2: Black Friday vs Normal Week
1. Set date range: Nov 24-30 (Black Friday week)
2. Choose: "Custom Date Range"
3. Set comparison: Nov 10-16 (normal week)
4. Result: See impact of Black Friday

### Scenario 3: Q4 vs Q3
1. Set date range: Oct 1 - Dec 31
2. Choose: "Quarter over Quarter"
3. Result: Compares to Jul 1 - Sep 30
